# 收尾汇报

只有负责人使用。中途不发，只在两种时候发：任务完成并合并后；任务被挂起时。

## 步骤

1. 先更新 Notion 看板上这一行：状态、最终用的模型和档位、失败次数、分支、结果一句话。
2. 再发 Slack 给 Dot 主管（用户对接的秘书）。第一次找不到 Dot 的频道或账号时，在 Slack 里搜索 "Dot"；仍找不到就问用户一次，并派子代理把结果记进全局 CLAUDE.md，以后不再问。
3. 消息用简短中文，带看板链接：

```
【完成】<项目> · <任务名>
做了什么：<一两句>
改动：<PR 或提交链接>
测试：<结果>
遗留：<没有就写「无」>
看板：<链接>
```

挂起时把第一行换成【挂起】，并写清：卡在哪、试过什么（模型和档位）、需要谁做什么。

4. 发完后调用 shuijiao 技能。
