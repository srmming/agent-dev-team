# 快修（对接窗口）

对接窗口只用于简单的沟通和小改动，例如前端样子、操作流程这类要用户亲眼看着调的事。改完必须上报负责人，合并照样走验收和 Codex 审核。

## 负责人这边

1. 起一个短名字 `<slug>`（英文小写加连字符）。
2. 建分支和独立工作副本，分支名必须以 `kuaixiu/` 开头——守卫 Hook 靠这个前缀认出对接窗口并放行改文件：
   `git worktree add -b kuaixiu/<slug> ../<项目名>-kuaixiu-<slug>`
3. 在看板记一行，状态「对接中」。
4. 在那个工作副本目录里另起一个会话，第一条消息写清：要改什么、现状、相关文件、只在这个分支上改。用当前环境里能新开会话的方式；如果没有这种能力，告诉用户一句话：在哪个文件夹开新对话。
5. 继续处理别的任务，不要等。

## 对接窗口交回之后

收到对接窗口的上报（或用户转来的摘要）后，按普通任务对待：

1. 读 `git diff <主分支>...kuaixiu/<slug>` 验收。
2. 改动超出「小改动」的范围，就拆成普通任务重新派。
3. 合并（Codex 审核由 Hook 自动触发）。
4. 更新看板，清理工作副本：`git worktree remove <路径>`。
