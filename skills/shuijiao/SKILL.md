# 睡觉（整理记忆）

模仿人睡觉时整理脑子：回顾刚结束的任务，分三步。负责人不能改文件，所以所有写入都派一个子代理去做，自己只决定写什么。

## 1. 丢掉

不记录：试错过程、失败的中间版本、已合并任务的细节（看板上一行结果就够）、过时的临时约定。

## 2. 留下，分三处放

| 内容 | 放哪 |
|---|---|
| 项目进度和做过的决定（含原因） | Notion 看板 |
| 这个项目的规矩和踩过的坑 | 项目的 CLAUDE.md |
| 用户的习惯和偏好 | 全局 CLAUDE.md |

写之前先读目标位置：已有同样的内容就更新，不重复记。每条一两句，写结论，不写经过。

## 3. 沉淀技能

- 同一套做法出现 2 次以上，才写成技能。只出现一次的不写。
- 先查现有技能：有类似的就更新，不新建。
- 新技能写到用户的技能目录（`~/.claude/skills/<名字>/SKILL.md`），说明什么时候用、按什么步骤做。
- 顺便清理：很久没用过、或被证明不好用的自建技能删掉。

## 4. 睡完

用两三句话告诉用户这次留下了什么、新建或更新了哪些技能。如果这个对话已经很长，建议开一个新的负责人对话，从干净的上下文开始。
